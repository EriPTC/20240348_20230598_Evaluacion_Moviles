# Nexora

Nexora es una aplicación desarrollada con React Native y Expo. Permite registrar usuarios, iniciar sesión y consultar o actualizar la información del perfil almacenada en Firebase.

## Funcionalidades

- Registro de usuarios con nombre completo, fecha de nacimiento, carnet institucional y URL de imagen.
- Autenticación mediante correo electrónico y contraseña.
- Perfil con visualización y edición de datos.
- Cierre de sesión y control automático de la sesión activa.
- Componentes reutilizables para formularios y botones.
